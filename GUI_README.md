# GUI Bot: простая инструкция

Инструкция предназначена для Windows и папки проекта:

`C:\Users\neved\Documents\Bot`

GUI использует реальные вкладки и кнопки программы: **Профили**, **Базовые экраны**, **Память**, **Фарм**; кнопки **Обучить выбранный урок**, **Обновить**, **Удалить выбранную**, **Добавить этаж**, **Старт**, **Стоп**.

## 1. Что нужно подготовить

1. Подключите телефон или эмулятор к компьютеру.
2. Установите **Python** с сайта python.org. В установщике включите **Add Python to PATH**.
3. Установите **LDPlayer** и **ADB**, если они ещё не установлены.
4. Запустите LDPlayer и убедитесь, что устройство видно командой `adb devices`.
5. Не переименовывайте файлы `config.yaml`, `main.py`, `gui.py` и папки `data`, `knowledge`.

## 2. Как обновить папку Bot

### Вариант A: через GitHub

1. Остановите фарм кнопкой **Стоп** и закройте GUI.
2. Откройте командную строку: нажмите **Пуск**, введите `cmd`, нажмите Enter.
3. Выполните команды:

```bat
cd /d C:\Users\neved\Documents\Bot
git pull origin main
```

4. Если Git сообщает о незаписанных изменениях, сначала сделайте копию папки `data` или отмените изменения только после проверки.
5. После обновления снова запустите GUI.

### Вариант B: ZIP-файл

1. Скачайте ZIP из GitHub.
2. Распакуйте его во временную папку.
3. Сохраните свою папку `data` в безопасное место.
4. Замените содержимое `C:\Users\neved\Documents\Bot` файлами из ZIP.
5. Верните папку `data`, если она была в вашей старой копии.

Не запускайте программу из папки «Загрузки»: GUI должен находиться вместе с `main.py`.

## 3. Как запустить GUI

1. Откройте папку `C:\Users\neved\Documents\Bot`.
2. Дважды щёлкните `start_gui.bat`.
3. Скрипт сам перейдёт в свою папку и выполнит `py gui.py`.
4. Если GUI завершится с ошибкой, окно командной строки останется открытым. Скопируйте текст ошибки.
5. Закрывать окно командной строки можно после закрытия GUI.

Альтернативно запустите вручную:

```bat
cd /d C:\Users\neved\Documents\Bot
py gui.py
```

## 4. Одноразовое обучение базовых экранов

Обучение нужно выполнить один раз для профиля `base`. Оно не удаляет уже сохранённые знания.

1. Запустите GUI.
2. Откройте вкладку **Базовые экраны**.
3. В списке по очереди выбирайте уроки:
   - **Главное меню** (`main_base`);
   - **Выбор локации** (`location_select`);
   - **Меню героя — старт** (`hero_menu_start`);
   - затем экраны локаций `loc1`–`loc7`.
4. Для выбранного урока нажмите **Обучить выбранный урок**.
5. На телефоне или в LDPlayer покажите нужный экран. Следуйте подсказкам `main.py`.
6. Дождитесь сообщения об успешном завершении.
7. Нажмите **Обновить** и убедитесь, что статус урока стал обученным.
8. Повторите шаги для всех уроков.

### Порядок обучения

Сначала обучите три базовых экрана: **Главное меню**, **Выбор локации**, **Меню героя — старт**. Затем обучите иконки локаций `loc1`–`loc7`. Выбирайте в игре именно тот экран, который указан в подсказке урока.

## 5. Как добавить этаж скриншотом

Этаж добавляется на вкладке **Фарм**.

1. В поле **Локация** выберите нужную локацию (`loc1`–`loc7`).
2. Нажмите **Добавить этаж**.
3. В окне выбора файла выберите PNG-скриншот этажа.
4. Введите номер этажа, например `1`, и подтвердите.
5. GUI сохранит PNG в папке выбранной локации и обновит `floor_templates.json`.
6. Повторите операцию для каждого этажа.
7. В списке этажей проверьте, что появился нужный номер.

Требования к скриншоту:

- формат файла — **PNG**;
- скриншот должен быть сделан с того же разрешения и ориентации, что и фарм;
- на скриншоте должен быть понятный экран этажа;
- не используйте размытые, обрезанные или перекрытые изображения.

## 6. Как запустить фарм

1. Убедитесь, что базовые экраны и иконка выбранной локации обучены.
2. Убедитесь, что для выбранной локации есть нужные этажи в списке вкладки **Фарм**.
3. На вкладке **Профили** выберите рабочий профиль. Профиль `base` для фарма не используется.
4. На вкладке **Фарм** выберите **Локация**.
5. Выберите этаж в списке.
6. Нажмите **Старт**.
7. Следите за статусом и журналом GUI.
8. Для остановки нажмите **Стоп**. Подождите сообщения об остановке процесса.

Важно: кнопка **Старт** запускает существующий путь фарма через `main.py`. Для работы нужны корректные PNG-шаблоны и `floor_templates.json`; одно только наличие названий этажей не гарантирует успешное распознавание.

## 7. Как удалить иконку из памяти

Удаляйте только одну запись за раз и только когда фарм остановлен.

1. Остановите фарм кнопкой **Стоп**.
2. Откройте вкладку **Память**.
3. Выберите профиль, например `loc1`.
4. В списке выберите ровно одну запись.
5. Нажмите **Удалить выбранную**.
6. Подтвердите удаление.
7. Нажмите **Обновить** и проверьте список.

Удаляется выбранная запись и связанный PNG. Перед изменением создаётся файл `features.json.bak`; не удаляйте его, пока не убедились, что всё сделано правильно. Файлы с расширением не `.png` программа удалять не будет.

## 8. Типичные ошибки и решения

1. **«py не найден» или Python не запускается.**
   - Установите Python.
   - Включите **Add Python to PATH**.
   - Закройте и снова откройте командную строку.
   - Проверьте: `py --version`.

2. **Окно GUI сразу закрывается.**
   - Запускайте через `start_gui.bat`: при ошибке окно останется открытым.
   - Запустите вручную командой `py gui.py` и прочитайте текст ошибки.
   - Проверьте, что текущая папка — `C:\Users\neved\Documents\Bot`.

3. **Ошибка `No module named ...`.**
   - В командной строке выполните:

```bat
cd /d C:\Users\neved\Documents\Bot
py -m pip install -r requirements.txt
```

4. **ADB не видит устройство.**
   - Запустите LDPlayer.
   - Включите отладку ADB.
   - Выполните `adb devices`.
   - Если устройство помечено как `unauthorized`, подтвердите разрешение в эмуляторе.

5. **Профиль не появляется.**
   - Нажмите **Обновить** на вкладке профилей.
   - Проверьте наличие папки `data\profiles`.
   - Не используйте имя `base` для обычного фарма.

6. **Урок не обучается или экран не распознаётся.**
   - Повторно откройте нужный экран в игре.
   - Обучайте в указанном порядке.
   - Проверьте разрешение, масштаб и ориентацию окна.
   - Сделайте новый чистый скриншот.

7. **Фарм сообщает, что нет шаблона этажа.**
   - На вкладке **Фарм** выберите правильную локацию.
   - Нажмите **Добавить этаж** и выберите PNG.
   - Проверьте номер этажа и файл `floor_templates.json`.

8. **Фарм запущен, но ничего не находит.**
   - Проверьте базовые экраны и иконку локации.
   - Проверьте качество PNG и совпадение разрешения.
   - Убедитесь, что игра открыта и устройство подключено.
   - Посмотрите журнал GUI.

9. **Нельзя удалить запись.**
   - Остановите фарм.
   - Выберите ровно одну запись.
   - Проверьте, что связанный файл имеет расширение `.png`.
   - Если JSON повреждён, сначала сохраните `features.json.bak`, не перезаписывая его.

10. **После обновления пропали знания.**
    - Проверьте резервную копию папки `data`.
    - При обновлении Git не заменяйте свои данные без копии.
    - Не используйте команды сброса знаний без необходимости.

## 9. Важные ограничения

1. Реальный запуск Tkinter и ADB должен быть проверен на вашем Windows-компьютере.
2. Фарм зависит от корректных PNG-шаблонов и `floor_templates.json`.
3. Кнопка **Старт** использует существующий `main.py`; отдельная логика `nav.py` не является заменой этому пути.
4. При остановке Windows может оставить дочерний процесс ADB или игры. Если процесс не остановился, закройте его через Диспетчер задач после выхода GUI.
