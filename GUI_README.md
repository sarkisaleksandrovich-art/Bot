# GUI Bot: простая инструкция

## Важно знать

1. Папка проекта должна находиться здесь:
   `C:\Users\neved\Documents\Bot`
2. В проекте сейчас есть `gui.py`, `main.py` и `config.yaml`.
3. GUI использует реальные кнопки: **Проверка**, **Снимок**, **Обучение**, **Обучение экранов (только)** и **Стоп**.
4. В `main.py` нет отдельного режима GUI-фарма и флагов `--gui`, `--gui-location`, `--gui-floor`. Поэтому кнопка GUI-фарма не добавляется: запуск несуществующей команды был бы ошибкой.
5. Модули `gui_base.py`, `gui_memory.py`, `gui_farm.py` и `nav.py` отсутствуют. Вкладки, которым нужны эти файлы, не заработают, пока файлы не будут добавлены.

## 1. Как обновить папку проекта

1. Закройте GUI и остановите фарм кнопкой **Стоп**, если он запущен.
2. Сделайте копию папки `C:\Users\neved\Documents\Bot` на случай ошибки.
3. Откройте страницу проекта на GitHub и скачайте свежую версию ZIP.
4. Распакуйте ZIP во временную папку.
5. Скопируйте новые файлы в `C:\Users\neved\Documents\Bot`.
6. Если Windows спросит о замене файлов, подтвердите замену файлов программы.
7. Не удаляйте свои папки `profiles`, `knowledge`, `screenshots`, если в них уже есть обучение. Если архив содержит такие папки, сначала сравните их с резервной копией.
8. Убедитесь, что в корне папки есть `gui.py`, `main.py`, `config.yaml` и `start_gui.bat`.

## 2. Подготовка перед первым запуском

1. Запустите LDPlayer.
2. Включите ADB в LDPlayer.
3. Проверьте, что Python установлен. В командной строке выполните:
   ```bat
   py --version
   ```
4. В папке проекта установите зависимости:
   ```bat
   cd /d C:\Users\neved\Documents\Bot
   py -m pip install -r requirements.txt
   ```
5. Если проект использует другое имя профиля или путь ADB, проверьте `config.yaml`.

## 3. Как запустить GUI

1. Откройте папку `C:\Users\neved\Documents\Bot`.
2. Дважды щёлкните `start_gui.bat`.
3. Скрипт сам перейдёт в папку проекта и выполнит `py gui.py`.
4. Если возникнет ошибка, окно командной строки останется открытым. Прочитайте текст ошибки и только потом нажмите любую клавишу.
5. Другой способ запуска:
   ```bat
   cd /d C:\Users\neved\Documents\Bot
   py gui.py
   ```

## 4. Одноразовое обучение: порядок действий

Обучение нужно выполнить на каждом профиле и для каждой нужной локации.

1. В поле **Профиль** выберите профиль. Для первого запуска не используйте профиль `base`.
2. В поле **Локация** выберите нужную локацию: `loc1`, `loc2`, `loc3`, `loc4`, `loc5`, `loc6` или `loc7`.
3. Поля **Этаж от** и **до** оставьте пустыми, если нужно обучение всего диапазона.
4. Нажмите **Проверка**. Дождитесь завершения и убедитесь, что ADB и скриншот работают.
5. Нажмите **Снимок**, если хотите проверить сохранение текущего экрана в папке `screenshots`.
6. Нажмите **Обучение** для полного одноразового обучения базовых экранов и элементов, которые поддерживает текущий код.
7. Если нужны только экраны без полного обхода, нажмите **Обучение экранов (только)**.
8. Дождитесь сообщения о завершении. Не закрывайте GUI во время обучения.
9. Повторите шаги для других локаций и профилей.

Не нажимайте **Обучение** одновременно с другой операцией. Для остановки используйте **Стоп**.

## 5. Как добавить этаж скриншотом

1. Запустите LDPlayer и откройте нужную локацию.
2. Перейдите на нужный этаж и оставьте на экране устойчивый, правильный вид.
3. В GUI выберите нужный **Профиль** и **Локацию**.
4. В поле **Этаж от** укажите номер этажа. В поле **до** укажите тот же номер, если нужен только один этаж.
5. Нажмите **Снимок**. Файл сохранится в `screenshots` с датой и временем.
6. Для добавления снимка в память используйте доступную вкладку обучения только после того, как нужный модуль будет добавлен в проект. Сейчас `gui_memory.py` отсутствует, поэтому проверить кнопку добавления этажа через GUI нельзя.
7. Не переименовывайте и не перемещайте снимок до завершения обучения.

## 6. Как запустить фарм

1. В текущем состоянии репозитория полноценный запуск фарма через GUI не подключён.
2. Причина: `main.py` поддерживает `--check`, `--capture`, `--teach`, `--teach-only`, `--profile`, `--floor-from`, `--floor-to`, `--config`, но не поддерживает `--gui` и параметры GUI-фарма.
3. Поэтому не пытайтесь добавлять к команде флаг `--gui`: он не работает.
4. Перед запуском фарма сначала нужно добавить и проверить рабочий фарм-модуль и навигацию (`gui_farm.py`, `nav.py` или соответствующую реализацию), а затем отдельно подключить команду запуска в `main.py`.
5. До этого используйте GUI только для проверки, снимков и обучения.

## 7. Как удалить одну иконку из памяти

1. В доступных файлах проекта нет проверенной реализации удаления ровно одной иконки.
2. Не удаляйте вручную весь профиль или `rules.json`/`features.json` без резервной копии: можно потерять всё обучение.
3. Сделайте копию папки профиля.
4. Удаляйте только запись нужной иконки вручную лишь если точно знаете формат файла и её уникальное имя.
5. После изменения запустите **Проверка** и затем повторите обучение нужного элемента.
6. Кнопки **Сброс знаний** в GUI нет; не используйте несуществующую кнопку.
7. Команда `--reset-knowledge` в `main.py` сбрасывает знания профиля целиком после подтверждения, а не одну иконку. Используйте её только после резервного копирования:
   ```bat
   cd /d C:\Users\neved\Documents\Bot
   py main.py --reset-knowledge --profile ИМЯ_ПРОФИЛЯ
   ```

## 8. Типичные ошибки и решения

1. **`'py' is not recognized` / не найден Python**
   - Установите Python для Windows.
   - При установке включите добавление Python в PATH.
   - Закройте и заново откройте командную строку.

2. **Окно сразу закрывается**
   - Запускайте через `start_gui.bat`: при ошибке он оставляет окно открытым.
   - Либо запускайте из командной строки и скопируйте полный текст ошибки.

3. **`config.yaml` не найден**
   - Проверьте, что команда выполняется из `C:\Users\neved\Documents\Bot`.
   - Не запускайте `gui.py` из другой папки.
   - В `start_gui.bat` переход в правильную папку выполняется автоматически.

4. **Не найден `gui_base.py`, `gui_memory.py` или `gui_farm.py`**
   - Это отсутствующие файлы проекта, а не ошибка ваших действий.
   - Восстановите их из правильной версии проекта или дождитесь их добавления.

5. **ADB не подключён**
   - Запустите LDPlayer.
   - Включите ADB.
   - Проверьте путь к `adb.exe` в `config.yaml` или установите Android Platform Tools.
   - Нажмите **Проверка** ещё раз.

6. **Снимок не создаётся**
   - Проверьте ADB и права на запись.
   - Убедитесь, что папка `screenshots` доступна для записи.
   - Не закрывайте LDPlayer во время операции.

7. **Ошибка кодировки в окне лога**
   - Перезапустите GUI через `start_gui.bat`.
   - Скрипт и GUI используют UTF-8; повреждённый вывод заменяется читаемыми символами.

8. **Фарм не запускается с `--gui`**
   - Это ожидаемо: такого флага нет в актуальном `main.py`.
   - Сначала нужна реализация фарма и подключение команды в `main.py`.

9. **Обучение видит неправильный экран**
   - Остановите операцию кнопкой **Стоп**.
   - Верните LDPlayer на нужную локацию и этаж.
   - Повторите **Снимок**, затем обучение.

10. **Не получается удалить одну иконку**
    - В текущей версии отдельная функция удаления одной иконки не проверена.
    - Восстановите `gui_memory.py` с такой функцией или обратитесь к разработчику. Не используйте полный сброс без резервной копии.
