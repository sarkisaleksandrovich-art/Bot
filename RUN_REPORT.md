## Краткая инструкция запуска

В корне репозитория на Windows:

```bat
start_gui.bat
```

Или из командной строки:

```bat
python main.py --gui
```

Для проверки без GUI:

```bat
python main.py --check
python main.py --list-profiles
```

Для навигации используются `--navigate` вместе с `--location` и, при необходимости, `--floor`; точный порядок параметров смотрите через:

```bat
python main.py --help
```
