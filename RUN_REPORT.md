## 4. Вердикты и ошибки

Общий вердикт: **FAIL**.

Причины FAIL:

1. В репозитории отсутствует `data/base/nav.json`; его фактическое содержимое проверить нельзя.
2. В дереве не найдены PNG-шаблоны, необходимые для готовой навигационной цепочки.
3. Реальный запуск на Windows/LDPlayer и через ADB не выполнялся.
4. Захват изображения в callback `gui_base.py` может блокировать Tkinter.
5. В `gui_memory.py` при ошибке удаления PNG JSON и PNG могут стать несогласованными.
6. Полная остановка активной ADB-операции через GUI не подтверждена.
7. Остался спорный пункт: в GUI есть кнопка `--list-profiles`, хотя ранее заявлялось её удаление.
8. Некоторые пути требуют запуска из корня проекта.
9. Реальную кодировку Windows-консоли, ADB и внешних процессов проверить без Windows нельзя.

## 6. Что пользователь должен проверить вручную

1. На Windows из корня проекта запустить `start_gui.bat`.
2. Проверить, что открывается GUI и работают вкладки навигации, памяти и фарма.
3. Подключить LDPlayer/ADB и выполнить тест `--navigate --location ... --floor ...`.
4. Создать через вкладку базы реальный профиль и убедиться, что появляется `data/base/nav.json` и PNG-шаблоны.
5. Проверить выбор этажей, запуск фармы и корректную остановку.
6. Проверить UTF-8 в консоли и выводе subprocess.
7. Проверить, нужна ли кнопка `--list-profiles`; при необходимости удалить её или подтвердить оставление.
8. Проверить отсутствие зависания окна во время захвата изображения.

## 7. Краткая инструкция запуска

Из корня репозитория на Windows:

```bat
start_gui.bat
```

Или из командной строки:

```bat
python gui.py
```

Навигацию без GUI запускать из корня проекта с параметрами, описанными в `GUI_README.md`, например:

```bat
python main.py --navigate --location <location_id> --floor 1
```

Для полноценного запуска нужны Python-зависимости из `requirements.txt`, доступный ADB/LDPlayer и созданные профили навигации с шаблонами.
